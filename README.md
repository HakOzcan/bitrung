# Bitrung

Turn your video files into adaptive HLS streams: pick the qualities,
keep HDR, add movie info.

In streaming, the set of quality versions is called a bitrate ladder.
Each version you pick is one rung of it, hence the name.

**Status:** early development, not usable yet.
